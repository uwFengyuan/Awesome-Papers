# Awesome Papers

[English](README.md) · [简体中文](README.zh-CN.md)

[GitHub](https://github.com/uwFengyuan/Awesome-Papers) · [Hugging Face](https://huggingface.co/datasets/OxFengyuan/Awesome-Papers)

按研究方向、具体任务和会议属性组织的精选长文论文库。

## 收录范围

涵盖 2017–2026 年 ICML、ICLR、ACL、EMNLP、NeurIPS、AAAI 的长文。

- **精选论文**：Main 中的 Best、Outstanding、Oral，以及符合相同条件的 NeurIPS Datasets / Benchmarks / Evaluations track 论文。
- **AI for Finance**：上述会议 Main 和 Findings 中的金融相关长文，不限奖项或展示形式；Main 与 Findings 分别浏览。Findings 仅收录金融相关论文。

不收录短文、Workshop、Demo、Industry、Journal-to-Conference 和独立 Position track 论文。
